# 사람인 평균연봉 데이터 외부 게시·재배포 권한 확인 기록

- 확인 일자: 2026-11-07
- 확인 주체·방법: 프로젝트 소유자(GitHub 계정 raspos)가 작업 대화에서 "사람인 데이터의 외부 게시·재배포 권한이 확인됐다"고 직접 통지함.
- 허용 범위(통지 내용 기준): 외부 게시(화면 표시)와 재배포(정적 JSON 공개) — 두 가지를 모두 포함하는 것으로 이해하고 공개 빌드에 포함함. 대상은 사람인 평균연봉(원 단위 값과 표시연도)과 사람인 전용 기업의 이름·공개 식별자에 한정하며, 매칭 근거·원본 URL·내부 감사 필드는 공개하지 않는다.
- 이 저장소에는 허락 문서 원본(서면·이메일 등)이 없다. 근거 원본은 소유자가 보관하며, 허락 범위가 위 이해와 다르거나 철회되면 `config/publish.yaml` 의 `saramin_permission` 을 `unconfirmed` 로 되돌리고 `saramin_in_site: false` 로 DART 만 배포해야 한다.
- 이 기록은 배포 차단 장치(check_public·package_site·pages.yml·publish_release)를 푸는 근거 파일이다.
