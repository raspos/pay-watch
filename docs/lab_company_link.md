# LAB ↔ 기업 상세 페이지 연동 방식 (설계 기록, 이번 단계에서는 구현하지 않음)

## 목적
기업 상세 페이지에서 ① DART 공시 평균급여 ② 평균근속연수 ③ 해당 산업의 근속 구간별 평균임금(LAB)을 **나란히** 보여준다. 기업 평균과 정부 통계는 모집단·급여 정의(공시: 사업연도 지급 총액÷직원 / 노동부: 월임금총액×12)·기간이 달라 **직접 비교 순위·우열 판정을 만들지 않는다**. "3년 차/7년 차 예상 연봉" 같은 표현은 쓰지 않는다.

## 연결 규칙(제안)
1. 기업의 DART 업종코드(KSIC) → LAB 산업 분류 매핑표를 **사람이 검수한 CSV**(`config/lab_industry_map.csv`: ksic_prefix, lab_raw_name)로 관리한다. 자동 추정·유사도 매핑은 쓰지 않는다.
2. 매핑 우선순위: KSIC 3~4자리(중분류 이름이 명확한 경우) → 없으면 표시하지 않는다(대분류로 폴백하지 않는다).
3. 매핑이 없거나 한 코드가 여러 산업에 걸치면 LAB 블록을 숨기고 "산업 통계 연결 불확실" 문구도 보여 주지 않는다.
4. 데이터: `site/data/lab/lab.json`의 `industry[].raw`(원자료 분류명)를 키로 쓰고, 기업 shard에는 `lab_industry_id`만 추가한다(값은 중복 저장하지 않는다).
5. 표시: 기업 카드 아래에 "이 산업의 근속 구간별 평균(고용노동부 2025)" 미니 그래프+표(LAB 화면과 같은 컴포넌트). 공시 평균급여는 별도 카드로 두며 같은 축에 겹치지 않는다. 문구: "회사 평균과 정부 통계는 기준이 달라 비교하지 않습니다."
6. 기존 파이프라인(국민연금·DART)은 읽기 전용으로만 사용하고 변경하지 않는다.

## 선결 과제
- 매핑표 작성과 오류 검수(PHASE 2에서 수동 매핑 10건을 만들었지만 일반화 검증 없음).
- 평균근속연수가 비어 있는 법인(은행 등)의 파싱 보완 — 표시 항목으로 쓰기 전에 필요.
